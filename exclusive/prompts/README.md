# Prompts — the exact text, kept because it cannot be rewritten

CLAUDE.md section 5: **never reword anything that produced an approved result.**
That rule is unenforceable if the words are not written down. Every prompt in
this production lived only in a chat transcript until now, and section 8 already
records what happens to things that live only in a transcript.

## Naming

| suffix | meaning |
|---|---|
| `-DELIVERED-<job-prefix>` | this exact text produced that job. **Byte-frozen. Never edit it.** |
| `-PROPOSED` | written, priced, not yet shot |
| `-ABANDONED-<job-prefix>` | shot and rejected — kept so the mistake is not repeated |

## The rule for editing

A `-DELIVERED` file is a record of what happened, not a draft. To change a shot,
copy it to a new `-PROPOSED` file and change that. Editing the delivered text
destroys the only evidence of what produced the approved footage.

The byte-identical blocks section 4 requires — Chi's two pinned voice lines, her
skin block, her hair block, her no-ring block, the image-quality block — are
copied forward from the most recent delivered prompt, not retyped.
