## THE CUPS ARE THE EPISODE'S CLOCK — the best continuity device in this project

From the prop element, and worth reading before designing any other episode:

- **EXACTLY TWO cups exist in the whole episode**, one per woman. ChiChi ordered
  both before Nia arrived, so the second is already on the table when Nia sits.
- **Levels only ever go DOWN and are never refilled.** ChiChi arrived first, so
  **her cup starts LOWER and stays lower for the entire episode.**
- *"A level that rises between clips is the clearest possible signal that the
  footage was generated rather than filmed."*
- Branding never renders as legible lettering — generated type garbles.

**This is CLAUDE.md section 4a's prop rule executed properly**: a single tracked
object that makes six separate generations read as one continuous conversation.
